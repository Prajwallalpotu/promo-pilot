# Understanding the request

Users want a video, not a form. Ask as little as possible. Defaults are fine because the storyboard's settings line shows every one of them, and the user can change any of them in a single reply.

## Defaults (don't ask about these)

| Setting | Default | Unless the user's words say otherwise |
|---|---|---|
| Format | **vertical 9:16** if they mention Reels, Shorts, TikTok, Instagram, Stories or "reel"; **landscape 16:9** for YouTube, website or "launch video"; vertical if there's no hint | "square", "for LinkedIn feed" → square |
| Length | the tier's default (tiers.md) | a number they gave, or a platform limit |
| Tone | inferred from the subject: food, family or local business → warm; dev tools or SaaS → clean/polished; games or consumer apps → playful | their own words ("make it cinematic") |
| Goal | launch / promo | "feature", "teaser", "explainer", "hiring", "event" |
| Voiceover | **off** | they ask for voice, narration or a voiceover |
| Captions | **on if there's a voice** (many people watch muted), otherwise off | they say otherwise |
| Caption language | the voice's language | they name another |
| Colours and fonts | the source's own; for text input, proposed from the tone | they give brand colours or a logo |
| Mode | guided | "quick", "auto" (SKILL.md → Modes) |

## The only questions (one message, at most 3, usually none)

Ask only what you can't default:

1. **What the video is about,** if there's no URL, folder or description. Ask for a sentence or two covering what it is, who it's for, and how to get it.
2. **The voiceover language,** if they want a voice and didn't name one. Never assume English, and never infer it from their name, location or the website's language.
3. **Website permission,** for a URL that may not be theirs: "Is this your site, or do you have permission to use its brand?" If the answer is no, offer a clearly labeled, unofficial review style instead of an ad that looks official.

Anything else, such as "I don't know your audience", is a default plus a line in the storyboard, not a question.

If the voice needs a one-time install, that question comes first, at setup (setup.md), and can go in the same message as these.

## Languages

- Use exactly what the user named: "Hindi", "Hinglish", "Brazilian Portuguese". If the chosen provider can't do it, say so and offer the options (voiceover-captions.md → Languages). Never switch languages silently.
- Several languages ("English and Spanish versions") means one video per language. Build the first, get it approved, then make the others from the same plan.
